# Quod

Quod connects mathematical textbooks, lecture notes, and problem sets in one reader. Upload PDFs or LaTeX files to explore linked definitions, theorems, and proofs across documents. Follow references in place, browse a dependency graph, and ask questions about the page using voice. Revisit difficult results and export them as Anki flashcards.

**Tech stack:** Next.js, React, TypeScript, Python/PyMuPDF, PostgreSQL, Elasticsearch, Firebase Authentication and Firestore, OpenAI, and Deepgram. Docker runs the local services, with Render hosting the frontend.
